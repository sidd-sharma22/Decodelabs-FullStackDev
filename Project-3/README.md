# StudyHub API

A task management backend built using FastAPI and PostgreSQL.

## Features
- User CRUD
- Task CRUD
- PostgreSQL integration
- One-to-many relationships
- Validation
- Error handling
- Swagger documentation

## Tech Stack
- FastAPI
- PostgreSQL
- SQLAlchemy
- Pydantic
- Uvicorn

## Run Project

```bash
uvicorn app.main:app --reload
